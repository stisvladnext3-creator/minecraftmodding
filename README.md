# Epoch Armory — Fantasy Reforged 1.1.1

Мод для **Minecraft 1.21.1 · NeoForge 21.1.262 · Java 21**. Оружие, доспехи, щиты и кузнечная мастерская в стиле эпического фэнтези.

## Исправления 1.1.1

- Убрана чёрная полоса со лба шлема ламелляра.
- Направление всех видов оружия в руках приведено к ванильному мечу Minecraft. Поддерживаются обе руки и игроки-левши.
- Исправлены размеры в руке и инвентаре: двуручный меч заметно длиннее одноручного и в 3,75 раза длиннее кинжала; пика и другое древковое оружие самые длинные.
- Двуручный меч держится обеими руками от первого и третьего лица. При занятой второй руке атаки запрещены, пользоваться предметом во второй руке тоже нельзя. Это относится к ванильным и модовым щитам, еде и другим предметам. Освободи вторую руку, чтобы атаковать.

## Проверки и исходники

Сборка успешна, все **17 обязательных серверных GameTest прошли**. Клиентские проверки брони, щитов и оружия завершились успешно; сравнение направления оружия выполняется с настоящим ванильным мечом (720 проверок). Идентификаторы предметов, 707 рецептов станков и числовые характеристики сохранены. Для двуручного меча действует новое обязательное условие пустой второй руки.
