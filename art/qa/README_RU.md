# Игровая проверка брони 1.1.0

Все `armor_*.png` — новые неизменённые снимки клиента Minecraft 1.21.1 / NeoForge 21.1.262 с графикой Fantasy Reforged. Девять снимков показывают четыре конструкции, десять материалов, отдельные слоты, позы, узкую модель игрока, смешанный комплект, перезагрузку ресурсов и настоящее окно инвентаря.

Финальный клиентский запуск завершился `EPOCH_ARMOR_SUCCESS`. Проверены грани со скосами и UV-текстуры 512×512. Технические рендеры и исходный атлас материалов хранятся отдельно в `art/fantasy/`.

Воспроизведение: `bash gradlew runGameTestServer`, затем `bash gradlew runArmorSmoke` в графической среде.
