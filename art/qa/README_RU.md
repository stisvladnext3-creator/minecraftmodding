# Игровая проверка брони 1.1.1

Девять `armor_*.png` — неизменённые снимки клиента Minecraft 1.21.1 / NeoForge 21.1.262 с графикой 1.1.1. На ламеллярном шлеме удалена отдельная чёрная полоса над лицом. Проверены четыре конструкции, материалы, отдельные слоты, позы, смешанный комплект, перезагрузка ресурсов и окно инвентаря.

Запуск завершился `EPOCH_ARMOR_SUCCESS`. Воспроизведение: `bash gradlew runGameTestServer`, затем `bash gradlew runArmorSmoke` в графической среде.
