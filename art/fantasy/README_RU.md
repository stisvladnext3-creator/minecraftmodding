# Fantasy Reforged 1.1.1

`material_atlas.png` — исходный атлас материалов, созданный и скорректированный инструментом image_gen для этого обновления. Раскладка: 4×4; верхний ряд — сталь, золото, тёмный металл, дамаск; следующие ряды — ткани/кожа, кольчуга/чешуя/кость/дерево, четыре цвета кристаллов.

`armor_catalog.png` и `weapon_catalog.png` — технические ортографические рендеры фактических моделей и UV-текстур из ресурсов мода. Они не являются снимками игрового клиента. Настоящие снимки клиента находятся в `art/qa/`.

Экспорт: `python tools/fantasy_assets.py`, затем `python tools/render_fantasy.py`. Второй шаг также обновляет все 160 иконок брони из геометрии соответствующих слотов. Python, Pillow и numpy нужны только для изменения графики; готовые PNG и модели уже включены в проект.

Идентификаторы предметов, рецепты, параметры боя и конструкции щитов сохранены. Гранёная броня использует существующий рендерер HumanoidModel, копирующий позу персонажа. Объёмные вставки имеют яркий цвет, без собственного освещения.

В 1.1.1 со шлема ламелляра удалена чёрная полоса, а каталог оружия показывает фактическое соотношение размеров в руке. Обязательный двуручный хват длинного меча реализован клиентским рендерером и серверными ограничениями; отдельные проверки приведены в VALIDATION_RU.md.
